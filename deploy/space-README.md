# Cosmostars · пульт наземной смены

Веб-сервис оператора наземной смены для кейса «Автономное управление
спутниковой группировкой», КосмоХакатон 2026.

Откройте вкладку **«Жюри»** — там маршруты по критериям оценки: каждая кнопка
приводит сервис в состояние, в котором соответствующий критерий можно
проверить своими руками.

Исходники, метод и инструкция запуска — в репозитории проекта.
Документация API — на `/docs`.
